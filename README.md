# DeVerge AI 🚀

**An AI-Powered Developer Assistant**

DeVerge AI is an AI-powered development platform designed to help developers write, understand, debug, and improve code faster.

🌐 **Live Website:** https://de-verge-ai-frontend.vercel.app/

## ✨ Features

- **Code Generator** – Generate code using AI.
- **Code Debugger** – Identify and fix programming errors.
- **Code Explainer** – Understand complex code.
- **Code Optimizer** – Improve code quality and efficiency.
- **Test Generator** – Generate test cases.
- **AI Assistant** – Get AI-powered programming assistance.

## 🛠️ Technologies Used

- React.js
- Vite
- JavaScript
- Node.js
- Express.js
- AI Integration
- Capacitor
